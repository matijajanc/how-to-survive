# Worksheet 3 — Drill Log

**Untested preparation is a guess.** Every drill in this file has, for every
household that has ever run one, produced a list of things that did not work.
That is the point. Finding them now costs an uncomfortable weekend. Finding them
later costs much more.

**Rule: every drill produces a fix list and a shopping list. Nothing is complete
until those are closed.**

## Drill 1 — Blackout weekend

**Setup:** Friday 18:00, turn off the main breaker. Turn it back on Sunday 18:00.
No cheating with the car, no takeaways, no charging phones at work.

**What it tests**
```
[ ] Can we light the house comfortably, all evening, for two nights?
[ ] Did the fridge and freezer contents survive? (thermometer inside — record temps)
[ ] Can we cook three meals a day on the backup stove? How much fuel did it use?
[ ] Can we heat the room we're in? (winter run only)
[ ] Did the battery last? What was the state of charge at each morning?
[ ] Did the solar produce what we expected? (record the actual figures)
[ ] Could we charge phones, run the radio, run any medical device?
[ ] Did the inverter idle-drain surprise us?
[ ] Did we have to run the generator? For how long? On how much fuel?
[ ] Water: did anything depend on an electric pump we forgot about?
[ ] Did everyone know where the torches were, in the dark, without being told?
[ ] Were we bored? What did we do about it? Was it enough?
[ ] What did we cheat on, and why?
```

## Drill 2 — Water-off day

**Setup:** close the mains stopcock at 07:00. Reopen after 24 hours. Use only
stored and treated water.

**What it tests**
```
[ ] How much water did we ACTUALLY use in 24 h? (measure it — this is the point)
[ ] Did the toilet plan work? Did anyone refuse to use it?
[ ] Did the filter flow fast enough to keep up with demand?
[ ] Could we wash dishes, hands and bodies to a standard we could sustain?
[ ] Did the stored water taste acceptable? Did the children drink it?
[ ] Could we find and operate the stopcock, and drain the hot water cylinder?
[ ] Did we contaminate anything by mixing clean and dirty containers?
[ ] How long did hauling/filtering/pouring actually take each day?
```
**Record:**
```
Date: __________ People: ______ Season: __________
Water used in 24 h: ______ L total = ______ L/person

## Drill 3 — Eat-the-store week

**Setup:** seven days, no shopping, nothing fresh bought. Cook only from your
stored food. Keep cooking on your normal appliances — this drill is about the
food, not the fuel.

**What it tests**
```
[ ] Does the family eat it? Actually eat it, without complaint turning into revolt?
[ ] What ran out that we didn't expect? (usually: oil, yeast, spices, onions)
[ ] What did nobody touch? (stop buying it)
[ ] Do we know how to cook from raw staples — beans, wheat berries, milk powder?
[ ] How long does it take to cook this way? Is it compatible with a work day?
[ ] What did we miss most? (that's your comfort-layer shopping list)
[ ] Did anyone get constipated, tired, or unwell? (nutrition gap signal)
[ ] How much did we consume vs. what the plan assumed? Recalculate endurance.
```
**Record:**
```

## Drill 4 — Cold night

**Setup:** one winter night, heating off from 16:00 to 08:00. Warm room only.

```
[ ] How cold did the warm room get? The rest of the house?
[ ] Was the bedding enough? Did anyone not sleep?
[ ] How much fuel did one evening of the wood stove / backup heater use?
[ ] Did the draught-proofing and curtains make a measurable difference?
[ ] Did the CO alarm stay quiet? (if not — STOP, and fix it before repeating)
[ ] Could we dry laundry without condensation problems?
[ ] Did anyone complain of headache or nausea? (investigate immediately)
```

## Drill 5 — Isolation weekend

**Setup:** Friday evening to Sunday evening. Nobody leaves the property, nobody
comes in. Run the full decon protocol on anything delivered. Utilities stay on —
this drill is about the protocol and the psychology.

```
[ ] Did the entrance airlock work? Was it in the way? Did everyone use it?
[ ] Did we have the PPE we thought we had, and does it fit each adult's face?
[ ] Did we follow the protocol when it was inconvenient, or quietly skip it?
[ ] Sick room: could we set it up in 15 minutes? Is everything in the box?
[ ] Did we get on each other's nerves? What triggered it?
[ ] Did children have enough to do? Did the schooling plan hold?
[ ] Did everyone get privacy? Did anyone get none?
[ ] Did the daily routine hold, or did it dissolve by Saturday afternoon?
[ ] Did we ration the news, or did it take over?
```

## Drill 6 — Key-person-silent

**Setup:** the person who knows most about the systems (power, water, stove,
where everything is) says nothing and does nothing for a whole weekend. Someone
else runs the house.

**This is the drill everyone skips and the one that most often reveals a fatal
gap.** A pandemic is precisely the event that takes an adult out of action for
two weeks.

```
[ ] Could someone else start, run and monitor the power system?
[ ] Could someone else filter and treat water?
[ ] Could someone else light and manage the stove safely?
[ ] Does everyone know where the stopcock, breaker, gas valve, spares and
    documents are?
[ ] Is the written system manual good enough to follow without asking?
[ ] Could someone else feed and secure the animals?
```
