# 12 — Operating Cycles & Calendar

*A stockpile is a countdown. A cycle is a system. This chapter is what turns the
first into the second — the routines that keep stores rotated, gardens
producing, animals breeding, equipment working and people sane.*

**This is the chapter that answers "how do I make it repeat?"**

---

## 1. The four loops

Everything in this plan sits in one of four nested loops. If any loop stops, the
whole system quietly degrades until you notice it has failed.

```
┌─────────────────────────────────────────────────────────────────┐
│  ANNUAL LOOP   Seed → plant → harvest → preserve → save seed    │
│                Breed → raise → cull → keep breeding stock       │
│                Cut → season → burn wood → cut again             │
│  ┌───────────────────────────────────────────────────────────┐  │
│  │  SEASONAL LOOP   Sow, tend, harvest, store, rest          │  │
│  │  ┌─────────────────────────────────────────────────────┐  │  │
│  │  │  WEEKLY LOOP   Bake, launder, clean, inventory,     │  │  │
│  │  │                maintain, plan, rest                  │  │  │
│  │  │  ┌───────────────────────────────────────────────┐  │  │  │
│  │  │  │  DAILY LOOP   Water, power, animals, food,    │  │  │  │
│  │  │  │               sanitation, health, comms       │  │  │  │
│  │  │  └───────────────────────────────────────────────┘  │  │  │
│  │  └─────────────────────────────────────────────────────┘  │  │
│  └───────────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────────┘
```

**Plus the continuous indoor loops that run in any season, in any dwelling:**
sprouts (3–5 days) · microgreens (7–14 days) · mushrooms (3–5 weeks) ·
ferments (1–3 weeks) · sourdough (daily) · compost/wormery (continuous).
**These are the loops an apartment can run, and they are the reason a flat is
survivable for a year.**

## 2. The daily routine in a crisis

Structure is not bureaucracy — it is the thing that holds a household together
over months of confinement. Write this on a card and put it on the wall.

### Morning
| | |
|---|---|
| **07:00** | Wake at a fixed time. Everyone. Drifting sleep is the first sign of a household coming apart. |
| | **Health check:** anyone symptomatic? Temperature and pulse ox if so. Log it. |
| | **Light the stove**, put the kettle and the big pot on. One fire does breakfast, hot water and the room. |
| | **Water:** check levels, run the filter (it should be filtering continuously), top up the day's clean supply, fill the hand-wash station. |
| | **Power:** check battery state of charge, clear snow/leaves off the panels, plan the day's loads around the forecast. Charge everything while the sun is up. |
| | **Animals:** feed, water (break ice in winter), collect eggs, check every animal is well and the housing is secure. |
| **08:00** | **Breakfast together.** Eat as a household at fixed times — it anchors the day. |
| | **Rinse the sprout jars** (morning rinse). Check the microgreens and mushrooms. |

### Day
| | |
|---|---|
| **09:00** | **Radio check-in** with the mutual-aid group. |
| | **The day's main work**, assigned the night before: garden, wood, repairs, preserving, building, laundry, teaching. Everyone has a job. |
| **12:30** | Lunch. Usually the previous night's leftovers or something from the thermal cooker. |
| **13:30** | Second work block. Children: school work. Adults: rotate the heavy job. |
| **15:00** | **Start the evening meal early** — get it to the boil and into the thermal cooker, so it finishes itself with no more fuel. |
| | **Daylight tasks finish**: anything needing light gets done before dusk, always. |

### Evening
| | |
|---|---|
| **17:00** | **Secure for the night:** animals shut in, doors locked, tools in, blackout curtains closed, water containers refilled. |
| | **Rinse the sprout jars** (evening rinse). |
| **18:00** | **Dinner together.** No radio, no crisis talk. |
| **19:00** | **Radio check-in.** News window: **20 minutes, one source, then off.** |
| | **Household meeting (10 min):** what happened today, what's the plan tomorrow, who is doing what, is anyone struggling. |
| **20:00** | **Non-productive time, deliberately.** Cards, music, reading aloud, games, talking. This is not a luxury — it is the maintenance schedule for the people. |
| **22:00** | Lights out. Log the day in the household journal: weather, stores used, work done, anything that changed. |

**Rotate the unpleasant jobs** (emptying the toilet bucket, hauling water,
laundry) on a written rota. Nothing corrodes a household faster than one person
silently doing all the worst work.

## 3. The weekly cycle

| Day | Task |
|---|---|
| **Monday** | **Laundry.** One big batch — water heated once, washed, rinsed, hung. Reuse the water on the garden or for flushing. |
| **Tuesday** | **Bake day.** Bread for the week; the oven/stove is hot, so also roast, dry herbs, render fat, heat wash water. One fire, many jobs. |
| **Wednesday** | **Maintenance.** Sharpen tools, fix what broke, check the stove and flue, service one system properly. Something breaks every week; deal with it before it accumulates. |
| **Thursday** | **Garden/production day.** The big session: planting, weeding, harvesting, preserving. Start the next ferment. |
| **Friday** | **Inventory and stores.** Count what was used, update the written inventory, check for damp/pests/spoilage, rotate stock forward, set next week's ration. |
| **Saturday** | **Projects and improvements.** Build the thing you've been meaning to build. Also: proper wash day for people. |
| **Sunday** | **Rest, and celebrate something.** A better meal. A game. Contact with people outside the household. **Take the day off deliberately — burnout is a survival risk.** |

**Also weekly:** test the CO and smoke alarms · check the animals for mites and
parasites · clean the water filter housing · check battery water if you have
lead-acid · full handover briefing so everyone knows the state of every system.

## 4. The monthly cycle

- **Full inventory count** against the written record. Reconcile. Calculate
  **days of endurance remaining** for water, food, fuel, medicine and cover
  material. **Write the number down and track the trend** — this single number
  tells you whether your rationing is right, months before you would otherwise
  notice.
- **Run the generator** for 30 minutes under load (unused engines seize; fuel
  goes stale in carburettors). Check oil.
- **Rotate fuel.** Use the oldest petrol in the car, refill the can.
- **Rotate water.** Empty, clean and refill a share of the storage.
- **Check and rotate medicines.** Anything within 3 months of expiry moves to the
  front for use.
- **Test the radios**, charge every battery bank, verify the group's comms plan.
- **Deep clean** one system: the water filter elements, the stove and flue, the
  coop, the food store.
- **Group meeting** with the mutual-aid households — in person if possible.
- **Skills hour:** teach one household member one thing they can't yet do.
- **Review the plan.** What changed? What did we learn? Update this document.

## 5. The garden year — Central Europe, month by month

*Adjust to your own last frost (assumed mid-April to early May) and first frost
(assumed mid-October).*

| Month | Sow / plant | Harvest | Other |
|---|---|---|---|
| **January** | Under cover: nothing much. Order seed **now** — good varieties sell out. | Leeks, parsnips, kale, Brussels sprouts, winter salad (tunnel), stored roots | Plan the rotation · prune apples and pears · sharpen and oil all tools · force rhubarb · repair structures · check the store for rot weekly |
| **February** | Indoors/heated: onions, leeks, chillies, aubergines, early tomatoes. Cold frame: broad beans, early peas | As January + forced rhubarb | **Chit seed potatoes** in a light, cool place · turn compost · finish pruning · lime beds that need it |
| **March** | Indoors: tomatoes, brassicas, celery. Direct under fleece: broad beans, peas, spinach, radish, early carrots, parsnips. Plant onion sets and shallots | Purple sprouting broccoli, leeks, chard, spring greens | **The hungry gap begins** · prepare beds (compost on top, no dig) · net everything as it emerges · sow green manure on beds not yet needed |
| **April** | **Plant maincrop potatoes (mid-month)** · direct sow beetroot, carrots, lettuce, chard, more peas · plant out onions and early brassicas | PSB, rhubarb, asparagus (from year 3), overwintered salads, first radish | **Peak hungry gap** — lean on stores and sprouts · watch for late frosts, keep fleece to hand · harden off seedlings |
| **May** | **After the last frost:** plant out tomatoes, squash, courgettes, cucumbers, sweetcorn, French and runner beans, celeriac, leeks | Asparagus, rhubarb, salads, spinach, first broad beans, early potatoes (late month) | Earth up potatoes · first comfrey cut · mulch everything · slug patrol nightly · succession-sow salad every 2 weeks from now |
| **June** | Succession salad, carrots, beetroot, French beans, chicory, kale and winter brassicas for autumn | Peas, broad beans, strawberries, early potatoes, salads, garlic scapes, first courgettes | Water deeply · second comfrey cut · summer prune fruit · make hay/dry comfrey for animal feed · start preserving |
| **July** | **Sow the winter crops now:** kale, chard, spring cabbage, winter salads, turnips, oriental greens. Plant out leeks and PSB | Everything begins: courgettes, beans, cucumbers, onions, berries, currants, early apples | **Blight watch** in warm wet weather — cut potato haulm at the first sign · preserve continuously · save seed from peas and beans |
| **August** | Winter salads, spinach, corn salad, land cress, oriental greens, overwintering onions (late) | **Peak harvest:** tomatoes, beans, cucumbers, sweetcorn, plums, apples, onions, garlic | **Peak preserving month** — canning, drying, fermenting daily · cure onions and garlic · save seed from tomatoes and lettuce · order autumn bulbs and bare-root stock |
| **September** | Green manure on every bare bed · overwintering broad beans (late) · plant strawberry runners | Maincrop potatoes, squash, apples, pears, beans (dry), tomatoes, roots | **Cure squash** 10 days in the sun · dry potatoes in the dark 2 weeks before storing · load the root cellar · final seed saving · take hardwood cuttings |
| **October** | **Plant garlic and overwintering broad beans** · green manure on everything bare | Roots, cabbage, leeks, kale, late apples, Jerusalem artichokes | **First frost mid-month** — lift the tender crops before it · clear and mulch spent beds · protect the tunnel · check all winter housing for animals |
| **November** | **Bare-root planting season: fruit trees, bushes, hedging.** Do this now. | Leeks, parsnips (sweeter after frost), kale, sprouts, stored everything | Prune apples and pears (not stone fruit) · build leaf mould cages · turn compost · drain and lag outdoor pipes · **stack next year's wood** |
| **December** | Rest. | Winter greens, stored roots, tunnel salads | **Plan next year from the notebook** · order seed · service tools · full inventory · repair · rest properly — this is the recovery month and you need it |

## 6. The livestock year

| Period | Poultry | Rabbits | General |
|---|---|---|---|
| **Jan–Feb** | Lowest laying. Extra light if you use it. Keep water ice-free. Deep litter keeps them warm. | Breed for spring litters if housing is warm enough | Feed stores at their lowest — check the maths against the calendar |
| **Mar–Apr** | **Laying picks up strongly.** Watch for the first broody hen. Set 8–12 fertile eggs under her. | Main breeding season begins; 4–5 litters ahead | Spring clean all housing; treat for mites; worm if needed |
| **May–Jun** | Chicks hatch and grow. Peak laying — **preserve the surplus** (water glassing, Ch. 03). Move to fresh range. | Litters every 5–6 weeks; weaning at 4–6 weeks | Rotate range/pasture; cut and dry hay and comfrey for winter |
| **Jul–Aug** | Growers on range, eating insects and garden waste — cheapest month of the year to keep poultry | Peak production; growers to freezer/jar at 10–12 weeks | **Sow and tend the fodder crops** (mangels, fodder beet, kale, pumpkins) |
| **Sep–Oct** | **Cull the cockerels** (16–20 weeks) and the oldest third of the hens. Preserve immediately. Moult begins; laying drops. | Reduce breeding; keep the best does and one or two bucks | **Lift and clamp the mangels and fodder beet. Store the pumpkins.** Buy in and store the winter feed — this is the month the whole system depends on. |
| **Nov–Dec** | Winter housing checked and draught-proofed (but ventilated). Feed mangels and pumpkins. Minimal laying. | Winter rest; feed hay and roots | Traditional pig slaughter and curing month · full feed audit: **do I have enough to reach March?** If not, cull now, not in February. |

## 7. Maintenance and rotation schedule

| Interval | Task |
|---|---|
| **Daily** | Filter water · check battery SoC · animals fed, watered and secure · sprouts rinsed ×2 · health check · stove ash and air control |
| **Weekly** | Test CO/smoke alarms · clean the filter housing · check stores for damp and pests · sharpen what was used · mite check on poultry · update the inventory |
| **Monthly** | Generator run under load · fuel rotated · a share of water storage emptied and refilled · medicines checked for expiry · radios tested · all batteries cycled · full inventory count and endurance calculation |
| **Quarterly** | **Eat-the-store week** · deep-clean a system · full first aid kit audit · drill (blackout, water-off, or isolation) · group meeting · review and update the plan |
| **Every 6 months** | Full inventory reconciliation · rotate stored water fully · rotate petrol · chimney check · panel tilt changed (spring/autumn) · test the whole power system under load · replace anything expired |
| **Annually** | **Chimney swept** · water filter elements replaced or deep-cleaned · water source lab-tested (well/spring) · fire extinguishers serviced · seed germination test · seed bank topped up · CO alarm test with a test gas · insurance and documents reviewed · **wood: burn this year's, season next year's, cut the year after's** · lime/pH test · rotate the medicine buffer · replace bleach |
| **Every 2–5 years** | Replace NaDCC tablets and O₂ absorber stock · replace vitamins · replace CO alarms (5–7 yrs) · replace polytunnel polythene (5–7 yrs) · refresh seed potatoes with certified stock · battery health check · refresh breeding stock genetics |

## 8. The rotation ledger

Keep one page, on the wall or in the binder, that answers **"what expires next?"**

```
ITEM                    QTY     PACKED/BOUGHT   REVIEW BY     ACTION
──────────────────────────────────────────────────────────────────────
Stored water (barrels)  600 L   2026-03         2026-09       Empty/refill
Petrol (jerry cans)     40 L    2026-05         2026-11       Into the car
Bleach                  5 L     2026-02         2027-02       Replace
Vitamins                12 mo   2026-01         2028-01       Replace
Seed bank               —       2026-01         2027-01       Germination test
Filter elements         2       2025-11         2027-11       Replace
Medicine buffer         3 mo    rolling         monthly       Use oldest first
Canning lids            500     2026-04         —             Count after season
Chicken feed            400 kg  2026-10         2027-04       Must last to March
Cover material          250 L   2026-09         —             Top up in autumn
Wood (this winter)      4 m³    seasoned 2025   burn 2026-27  Cut 2027-28's now
```

**Update it every month.** This one page is the difference between a system and a
pile of stuff.

## 9. The annual review

Once a year — **December is ideal** — sit down as a household and do this
properly. It takes an afternoon.

1. **Re-run the household audit** ([`worksheets/household-audit.md`](../worksheets/household-audit.md)).
   What changed? New baby, new condition, new medication, someone moved out,
   a child now old enough to have real jobs?
2. **Recalculate endurance in days** for every category. **What is the lowest
   number?** That is next year's priority, regardless of what you feel like buying.
3. **Read the garden notebook.** What actually grew well here? What failed twice?
   Stop growing what fails; plant more of what works.
4. **Read the drill log.** What broke? What did we not know how to do?
5. **Review the skills list.** What did we learn this year? What's next?
6. **Check the group.** Who joined, who left, what gaps opened?
7. **Set next year's targets:** one level up in the weakest category, two new
   skills, one new perennial planting, one new production cycle.
8. **Update this plan and print it again.** A plan that doesn't change is a plan
   nobody is using.

## 10. Cycles checklist

```
[ ] A written daily routine is on the wall, and everyone knows their jobs
[ ] Job rotation agreed in writing — nobody silently does all the worst work
[ ] Weekly rhythm established (laundry / bake / maintain / grow / inventory / rest)
[ ] Monthly inventory count and endurance-in-days figure being tracked
[ ] Rotation ledger written and updated monthly
[ ] Garden calendar adapted to OUR frost dates and pinned up
[ ] Livestock breeding calendar written; autumn feed audit scheduled
[ ] Fodder crops in the planting plan, not an afterthought
[ ] Wood cycle is two years ahead
[ ] Seed saved every year; germination tested every year
[ ] Continuous indoor cycles running NOW: sprouts, ferments, compost
[ ] Quarterly drill scheduled in the calendar
[ ] Annual review booked for December
[ ] A rest day every week, defended
```
